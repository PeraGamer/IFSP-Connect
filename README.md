IFSP Connect
Pietro Pereira
Engenharia de Computação

O objetivo do IFSP Connect é exibir todo o aprendizado durante o curso de Desenvolvimento Front-End. Ao decorrer de 3 módulos, um website fictício será adaptado e evoluído até uma versão final com recursos aprendidos durante as aulas. Após a conclusão, o aluno pode mostrar todo o conhecimento adquirido.
Utilizaremos o HTML para a criação do website, CSS para desenvolver estilos e o JavaScript para implementar funcionalidades interativas.
